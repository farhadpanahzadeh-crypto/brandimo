# قالب وب‌سایت برندیمو (Brandimo)

قالب کامل، واکنش‌گرا و راست‌چین وب‌سایت برندیمو با **HTML، CSS و JavaScript خالص**، بدون فریم‌ورک و بدون نیاز به سرور.
فایل‌های `.html` ریشه پروژه را مستقیم در مرورگر باز کنید یا روی هر هاست استاتیکی قرار دهید.

## ساختار پروژه

```
assets/
  css/
    tokens.css       توکن‌های Design System: رنگ، تایپوگرافی، فاصله، گوشه، سایه، Liquid Glass
    base.css         پایه، راست‌چین، دسترس‌پذیری، انیمیشن ورود
    components.css   دکمه، نشان، کارت‌ها، هدر، فوتر، فرم، جست‌وجو
    sections.css     بخش‌های صفحات و قواعد واکنش‌گرایی
    fonts.css        فونت وزیرمتن (میزبانی محلی)
  js/
    config.js        تنظیمات (مقصد ارسال فرم‌ها)
    main.js          منوی موبایل، جست‌وجو، اسلایدر رویداد، فیلترها، فرم‌ها
    search-index.js  فهرست جست‌وجو (ساخته‌شده خودکار)
  fonts/             Vazirmatn (SIL OFL)
  brand/mark.svg     نشانه برند (موقت)
build/
  data.mjs           همه محتوا: دوره‌ها، رویدادها، پروژه‌ها، رسانه، اطلاعات تماس
  partials.mjs       کامپوننت‌های مشترک: هدر، فوتر، کارت‌ها، بنرها
  pages.mjs          قالب هر صفحه
  build.mjs          تولید فایل‌های HTML
```

## ویرایش محتوا و طراحی

هدر، فوتر، کارت‌ها و بنرها کامپوننت مشترک هستند تا تغییر یک جزء در همه صفحات اعمال شود. برای ویرایش:

```bash
npm install
```

```bash
npm run build
```

- **محتوا** (دوره، رویداد، پروژه، اپیزود، اطلاعات تماس، شبکه‌های اجتماعی): `build/data.mjs`.
  هر مورد فقط یک بار ثبت می‌شود و خودکار در صفحه اصلی، صفحه حوزه مرتبط، آرشیو و جست‌وجو نمایش داده می‌شود
  (`featured` برای صفحه اصلی، `category` و `alsoOn` برای صفحات مرتبط).
- **رنگ، فونت، فاصله و افکت شیشه‌ای**: فقط `assets/css/tokens.css`.
- **تصاویر**: به هر مورد `visual.src` بدهید (مثلاً `assets/img/project.webp`). تا وقتی تصویر واقعی نیست، کاور برندشده جای آن را نگه می‌دارد.
- **فرم‌ها**: در `assets/js/config.js` مقدار `formEndpoint` را تنظیم کنید (مثلاً Formspree یا بک‌اند آینده). تا آن زمان فرم‌ها اعتبارسنجی می‌شوند و صادقانه اعلام می‌کنند که ارسال هنوز متصل نیست.

## Liquid Glass

افکت شیشه‌ای فقط در هدر، نوار «جدیدترین‌ها»، آثار هنری بنرها، پلیر رسانه، منوی موبایل و پنجره جست‌وجو استفاده شده است. این افکت شبیه‌سازی وب با `backdrop-filter` است و در مرورگرهای بدون پشتیبانی یا با `prefers-reduced-transparency` به پس‌زمینه یکدست و خوانا برمی‌گردد. در موبایل شدت blur کمتر است.

## موارد نیازمند اطلاعات واقعی

محتوای فعلی **نمونه** است (`sample: true`) و صفحات جزئیات این را اعلام می‌کنند. پیش از انتشار:

- شماره تماس، ایمیل، نشانی، لینک کانال ایتا و شبکه‌های اجتماعی (`site` در `build/data.mjs`)
- فایل رسمی لوگو از برندبوک (نشانه فعلی در `brandMark()` موقت است) و تأیید کدهای رنگ در `tokens.css`
- تصاویر واقعی دوره‌ها، رویدادها و پروژه‌ها
- تاریخ، مکان، سخنران، مدرس، هزینه و دستاوردهای واقعی
- مقصد ارسال فرم‌ها

## محدوده

این مخزن قالب فرانت‌اند است. پنل مدیریت، پایگاه داده و احراز هویت پیاده‌سازی **نشده‌اند**؛ ساختار `build/data.mjs` قرارداد داده‌ای است که بک‌اند یا CMS آینده باید همان را برگرداند.
